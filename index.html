판매이력 없는 상품 탐색기

도매꾹·도매매에서 아직 한 번도 팔리지 않은 상품을 공급사별로 찾고, 매일 원하는 개수만큼 골라 봅니다.

추출일 — 상품 — 공급사 —
도매매 마이박스에 담기 처음이면 펼쳐서 북마크 버튼을 먼저 설치하세요
  1. 처음 한 번: 아래 마이박스 담기 버튼을 브라우저 즐겨찾기 막대로 끌어다 놓습니다. 막대가 안 보이면 Ctrl+Shift+B.
  2. 도매매에 로그인합니다.
  3. 여기서 상품을 고르고 [도매매에 담기]를 누릅니다. 해시태그와 상품번호가 복사되고 도매매 상품검색이 열립니다.
  4. 열린 도매매 화면에서 즐겨찾기의 마이박스 담기를 누릅니다. 처음 한 번은 Chrome이 클립보드 읽기를 허용할지 묻습니다. 허용을 누르면 다음부터는 바로 진행됩니다. 차단하면 붙여넣기 창이 뜨니 Ctrl+V 후 확인을 누르세요.
  5. 번호 추가 → 수량별비례·구간별배송료 상품 제외 → 검색 → 전체선택 → 해시태그 → 마이박스담기까지 자동으로 진행됩니다. 검색 뒤 화면이 새로 열리면 마이박스 담기를 한 번 더 누릅니다.

이미 북마크를 설치했다면 지우고 새로 끌어다 놓아야 클립보드 읽기가 적용됩니다. 끌어다 놓기가 안 되면 [북마크 코드 복사]를 누르고, 즐겨찾기 추가 화면의 URL 칸에 붙여넣으세요. 도매매는 한 번에 2만 개까지 담을 수 있습니다.
